Daydesk 설치와 계정 연결 안내

1. 설치 위치와 시작 옵션 선택
다음 화면에서 설치 경로를 선택하세요. 바탕화면 바로가기, Windows 로그인 시 자동 실행, 명령줄에서 daydesk 사용 여부도 선택할 수 있습니다.

2. 설치 후 계정 연결
설치 완료 화면에서 Daydesk를 실행하면 설정의 ‘계정 연결’ 화면이 열립니다. TimeTree와 Todo Mate의 이메일·비밀번호를 각각 입력하고 ‘로그인·연결’을 누르세요. TimeTree에서는 사용할 캘린더도 선택하세요.
계정마다 ‘연결 방법’ 버튼으로 자세한 방법을 확인할 수 있습니다. 두 계정을 연결하기 전에는 위젯 배경이 불투명하며, 연결이 끝나면 저장된 투명도가 적용됩니다.

3. TimeTree MCP는 자동 설치
TimeTree MCP와 필요한 Python·Node 실행 환경은 설치파일에 포함되어 있습니다. Codex, 별도 MCP 등록, API 키 입력이 필요하지 않습니다.
Todo Mate도 본인 계정으로 바로 연결되며, Firebase 프로젝트나 API 키를 준비하실 필요가 없습니다.

4. PlayMCP 보조 연결은 선택 사항
PlayMCP(플레이MCP)는 Firebase 조회 한도에 걸렸을 때 사용하는 보조 조회입니다. 연결하지 않아도 Firebase를 통한 조회·추가·수정·삭제·완료 기능을 사용할 수 있습니다. PlayMCP에도 자체 조회 한도가 있습니다.

연결하려면:
  ① 앱의 설정 → 계정 연결 → PlayMCP 보조 연결에서 ‘PlayMCP 열기’를 누릅니다.
  ② 카카오 계정으로 로그인하고, ‘투두메이트’를 찾아 도구함에 추가합니다. 위젯에 연결한 것과 같은 Todo Mate 계정으로 인증합니다.
  ③ 도구함에서 ‘OpenClaw와 연결’을 누르고 데이터 제공에 동의한 뒤 ‘연결 프롬프트 생성’을 선택합니다.
  ④ 만들어진 연결 프롬프트 전체를 복사해 위젯의 입력칸에 붙여 넣고 ‘연결’을 누릅니다.
발급 후 10분 안에 입력하세요. 만료되면 새 프롬프트를 생성하세요. OpenClaw 프로그램을 따로 설치할 필요는 없습니다.
사이트: https://playmcp.kakao.com/
카카오 연결 안내: https://www.kakaocorp.com/page/detail/12012

5. 일정과 할 일 관리
위젯 상단의 ‘일정 추가’로 TimeTree 일정을 만들고, 달력의 일정을 누르면 제목·실제 캘린더 라벨·날짜·시간 등을 수정하거나 삭제할 수 있습니다. 반복 일정은 선택한 회차만 변경합니다. 장소·메모·URL은 필요할 때 펼쳐서 입력하세요.
Todo Mate의 + 버튼으로 할 일을 추가합니다. 추가·수정 창에서는 내용을 입력하고, 완료 처리는 목록의 체크박스로 합니다.
위젯 크기는 상하좌우 테두리와 네 모서리에서 드래그해 조절할 수 있습니다.

6. 지금 연결하지 않으셔도 됩니다
앱의 ‘건너뛰기 · 나중에 연결’을 누르면 다음 실행부터 연결 팝업을 자동으로 띄우지 않습니다. 나중에 위젯 상단의 설정 → 계정 연결에서 연결할 수 있습니다. 연결하지 않은 서비스의 일정·할 일은 불러오지 않습니다.

로그인 정보와 개인 일정 캐시는 설치파일에 포함되어 있지 않습니다. 연결한 계정 정보는 이 PC의 Windows 사용자에 연결된 암호화 저장소에 저장됩니다.
